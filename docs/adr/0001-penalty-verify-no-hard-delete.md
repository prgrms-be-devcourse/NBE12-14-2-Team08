# 벌칙 인증은 지우지 않고 상태만 되돌린다

벌칙 인증 행을 물리 삭제하면 방 종료 후 결산의 벌칙 수와 "느긋한 벌칙왕" 집계가 틀어지고, 시스템이 부과한 벌칙을 작성자가 지워서 피할 수도 있었다. 그래서 삭제 API를 없애고, 작성자는 검토 전 제출만 "제출 취소"하고, 방장은 이미 제출된 건도 "벌칙 초기화"할 수 있도록 했다. 두 경우 모두 설명, 사진 주소, 제출일을 비우고 미제출 상태로 되돌리며 행은 남긴다.

## Consequences

- 되돌린 벌칙은 결산의 벌칙 수에 계속 포함되고, 다시 제출하면 새 제출일 기준으로 지연 일수가 계산된다.
- DB의 사진 주소만 비우므로 Storage의 실제 사진 파일은 남는다. 파일 삭제는 별도 이슈에서 다룬다.
